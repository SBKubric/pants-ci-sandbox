# pants-ci-sandbox

Одноразовая песочница для проверки CI-пайплайна на базе Pants: stacked PR,
heavy/unit-разделение тестов, дифф-выборка таргетов.

Содержимое каталога `smart-cube/` — мок-проект (два сервиса поверх общей
библиотеки), нужен только чтобы у Pants было что собирать и тестировать.
Никакой полезной нагрузки здесь нет.

Сценарии проверки (K1–K18) прогонялись в этом репозитории вручную через
`gh` — ветки и PR приходили и уходили, а сам факт истории коммитов и
закрытых PR оставлен как есть для инспекции.
